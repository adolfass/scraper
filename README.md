# Заполнение прайс-листа автозапчастей ссылками на сертификаты ЕАЭС (scraper)

Скрипты сканируют публичный реестр ФСА (pub.fsa.gov.ru) и для каждой позиции
прайс-листа автозапчастей находят соответствующий сертификат/декларацию
соответствия и подставляют в выгрузку колонки:

`CertNumber | CertUrl | TNVED | CertType`

## Какую задачу решает проект

Вход — прайс-лист автозапчастей `Итоговый ИП.xlsx` (≈4 000 строк, лист `Лист1`,
без шапки; `BrandName` в колонке A, `Code` в B). Для каждого артикула нужно
указать документ о соответствии требованиям ТР ТС/ЕАЭС:

1. **Поиск.** Для каждого `Code` в реестре сертификатов ФСА находятся пары
   «артикул → идентификатор сертификата» (точное и подстрочное совпадение).
2. **Контроль бренда.** Ссылка ставится, только если `BrandName` совпадает с
   производителем / заявителем / товарным знаком сертификата. Поддерживаются
   группы-алиасы брендов (MANN-FILTER↔MANN+HUMMEL, FEBI↔FEBI BILSTEIN, …).
3. **Тиражирование.** Слабый тир (бренд найден в списке артикулов сертификата),
   опция «точного артикула» (сертификат оформлен на фактического изготовителя
   компонента, но артикул указан в нём дословно).
4. **ТН ВЭД.** Из карточки сертификата проставляются коды ТН ВЭД (через
   классификатор `tnved_tree.json`).
5. **Формат.** Выгрузка повторяет 12-колоночную структуру `Результат.xlsx`
   (ProdNum, Code, BrandName, ProdName, PriceOut, QTY, Commentary, BatchQty,
   CertNumber, CertUrl, TNVED, CertType).
6. Перенос («carry-over») готовых строк из эталонного `Результат.xlsx` и
   fallback на реестр деклараций (rds).

**Итог:** 3 821 строка выгрузки; 1 826 строк заполнены (1 823 с ТН ВЭД).
Бренд Zekkert исключён целиком.

## Состав

| Файл | Назначение |
|---|---|
| `fsa_api.py` | HTTP-транспорт к API ФСА (curl_cffi, браузерный TLS, persist-сессия), login, поиск сертификатов и деклараций |
| `pipeline.py` | «Политрежим»: ~1 запрос/с, таймауты с эскалацией, backoff, resumable логи |
| `build_output.py` | Шлюз брендов: `BRAND_ALIASES`, нормализация текста, проверка соответствия, ТН ВЭД |
| `ip_build.py` | **Главный билдер** выгрузки (выбор сертификата, TNVED, output) |
| `ip_probe.py`, `ip_decl_probe.py`, `ip_supervisor.py` | Сканеры реестра сертификатов и деклараций (последовательно, с резюмированием) |
| `en0_proxy.py` | Локальный прокси с привязкой к физическому интерфейсу (обход гео-блокировки реестра) |
| `other_sources.py`, `fetch_eae_docs.py` | Вторичные реестры (tech.eaeunion.org и др.) |
| `num2url.py`, `tnved_tree.py`, `resolve_tnveds.py` | Построение классификатора ТН ВЭД из реестра |
| `ref_carry.py`, `decl_carry.py` | Перенос эталонных строк и обработка деклараций |
| `analyze_features.py`, `blocked_exact.py`, `block_triage.py` | Аналитика: признаки заполненных артикулов, оценка «заблокированных» пар |
| `qa_final.py` | Контроль качества итогового файла (шапка, Zekkert, соответствие карт) |

## Использование

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt

# обязательные доступы к API реестра (пароль не захардкожен)
export FSA_USER=... FSA_PASS=...

cd /Users/mac/Downloads    # входной прайс указан в ip_build.SRC / SRC=...
OUT_FILE="Итоговый ИП_Результат.xlsx" \
RULE=any SUBSTR_TIER2=1 BRAND_WEAK=1 EXACT_OVERRIDE=1 \
.venv/bin/python ip_build.py
```

Переменные окружения:

| Переменная | Значение по умолчанию | Назначение |
|---|---|---|
| `FSA_USER` / `FSA_PASS` | — (обязательны) | учётные данные API реестра сертификатов |
| `RULE` | `any` | правило отбора пар `t` / `any` / `mix` |
| `SUBSTR_TIER2` | `0` | вторая ступень подстрочного совпадения |
| `BRAND_WEAK` | `0` | слабый тир бренда (совпадение в списке артикулов) |
| `EXACT_OVERRIDE` | `0` | принимать сертификат с артикулом дословно, даже если производитель ≠ бренду |
| `OUT_FILE` | `Итоговый ИП_Результат.xlsx` | путь к выгрузке |
| `FETCH` | `1` | докачивать недостающие карточки сертификатов |
| `DELAY` / `TIMEOUT_SCHED` | ~1 c / 30,90,150 | темп и таймауты полит-сканирования |

## Реестр ЕАЭС (tech.eaeunion.org)

API реестра (OData) отвечает, но `$filter=contains(productName, ...)` по
конкретному артикулу упирается в 504 Gateway Timeout (полный LIKE по огромной
текстовой таблице). Поэтому как источник ссылок реестр ЕАЭС не используется —
только перенос строк из эталонных файлов.
